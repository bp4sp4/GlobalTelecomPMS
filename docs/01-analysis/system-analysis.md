# 기존 시스템 분석 — 방송장비 컨설팅 문서자동화 시스템

> 분석 대상: `http://123.215.15.150:8000`
> 분석일: 2026-07-27
> 분석 방식: 읽기 전용(GET) 탐색. 데이터 변경/등록/삭제 없음.
> 목적: 동일 기능 풀스택 클론 구축을 위한 기능/데이터 명세

## 0. 개요

- **겉표지**: "서울특별시교육청 사업관리시스템 / 2026년 학교정보화지원체계(테크센터) 운영지원사업"
- **실제 정체**: 학교별 **방송/음향 장비 점검·컨설팅 보고서 자동화 시스템** ("문서 자동화 — 현장 작업 문서 생성 시스템")
- **백엔드 추정**: FastAPI(Python) — 미존재 경로에서 `{"detail":"Not Found"}` JSON 응답
- **핵심 데이터 소스**: `reports` 테이블(문서 자동 집계), `schools.json`(전체 학교 1414교 기본정보)
- **권한 구조**: `admin` / `guest`(예: `gtgt3`). guest는 CSV 업로드·원격접속목록 접근 불가(대시보드로 리다이렉트)

## 1. 인증 / 로그인 (`/`)

- 필드: 아이디, 비밀번호, "로그인 상태 유지" 체크박스, "비밀번호 찾기" 링크
- 소셜 로그인 버튼: Google, Microsoft (구현 여부 미확인)
- 회원가입 링크 존재
- 로그인 실패 시: "아이디 또는 비밀번호가 올바르지 않습니다" 배너
- 세션 기반 인증(쿠키). `/logout` 존재

## 3. 대시보드 (`/dashboard`)

- 상단 KPI 카드 4개(도넛 차트):
  - 컨설팅 진행: `109 / 300` (완료기준: 컨설팅 DONE=1 / 스피커선로 DONE=4)
  - 문서 자동합계: `384` (reports 테이블 자동 집계)
  - 완료: `109`
  - 진행률: `36.0%` (자동계산 완료 / 컨설팅대상)
- 원격 접속(최근 10분) 패널 — **admin 전용**
- 메시지 패널 — admin 공지 목록 + 입력창(최대 1000자) + 전송 (guest도 표시됨)
- 하단: "진행상태 표시 영역"(미구현 안내) + [문서관리로 이동]
- 좌측 사이드바: 문서관리(대시보드/문서관리/로그아웃/관제통계), 시스템(메인)

## 4. 문서관리 (`/docs`)

- 학교 검색: 학교명(초성/전체명) 입력 → **실시간 자동완성 드롭다운** → 선택
- 학교 선택 시 5종 보고서 카드 노출:
  1. **방송 장비 컨설팅 보고서** — 1차/2차 각각 저장/완료 상태 표시, [1차 작성]/[2차 작성] 버튼
  2. **방송 장비 목록**
  3. **스피커 선로 점검 보고서**
  4. **개선보고서**
  5. **방송사진**
- 상단: [학교 데이터 업로드](admin), [로그아웃]
- 학교 마스터 → 지청(교육지원청)·주소 자동 매핑

## 5. 보고서 5종 상세

### 5.1 방송 장비 목록 (`/docs/equipment`)
- 액션: 문서관리 홈 / PDF 출력 / CSV 출력 / 저장(초안 생성) / 로그아웃
- 기본 정보: 점검일자(date), 학교명, 지청, 주소 (학교 선택 시 자동)
- 장비 입력: 장비 검색(자동 추가) / 행 추가 / CSV·엑셀 파일 추가
  - 위치 선택기: ① 방송실 ② 중소형실(시청각실/특별실/다목적실/소강당/기타실) ③ 강당/체육관
  - 취급자 성명, 문서정렬
- 테이블 컬럼: No · 분류 · 장비명 · 제조사 · 모델/규격 · 수량 · 도입일자 · 설치위치 · 취급자 성명 · 상태 · 교체여부 · 삭제

### 5.2 스피커 선로 점검 보고서 (`/docs/speakerline`)
- 액션: PDF/CSV 출력 · CSV 입력 · CSV 붙여넣기 · 저장 · 완료 · 로그아웃
- 기본 정보: 학교명 · 점검일 · 교육지원청 · 취급자 성명 · 주소
- 섹션1 — 송출부 스피커 선로 점검(고정 4항목, 판정 양호/불량 + 비고):
  1. 앰프 랙 인입 스피커 선로 점검
  2. 스피커 선로 분배 장치 입력단 점검
  3. 스피커 선로 절체 장치 점검
  4. 방송 장비 보호 장치 점검
  → 대시보드 "스피커선로 DONE=4" 완료기준
- 섹션2 — 교실(실) 스피커 출력/음압 점검(행추가): No·층·위치·음압(dB)·출력상태·정격출력(W)·수량·판정·개선여부·비고
- 섹션3 — 스피커 선로 임피던스 측정(행추가): No·층·위치·방송실 출력단자·측정저항(Ω)·판정·개선여부·비고
- 메모 필드

### 5.3 개선보고서 (`/docs/improvement`)
- 기본 정보: 학교명 · 개선일자 · 교육지원청 · 취급자 성명 · 주소
- 장비 검색: 분류(전체/음향/영상/기타) + 검색 → 선택항목 행추가 (**개선보고서 전용 코드북**, 타 문서 미연동)
- 테이블: No · 분류(음향/영상/기타) · 장비명 · 제조사 · 모델/규격 · 수량 · 설치위치(방송실/시청각실/특별실/다목적실/소강당/기타실/강당·체육관/교실) · 개선금액 · 개선내용 · 삭제
  - 개선내용 옵션: 음향장비 교체/설치/점검조정, 영상장비 교체/설치/기타, 장비교체/선로작업/케이블작업
- 개선금액 합계 자동계산, 비고, PDF/CSV 출력

### 5.4 방송사진 (`/docs/equipment_photos`)
- 기본 정보: 학교명 · 지청 · 주소 · 촬영/점검일 · 담당자 · 메모
- 사진 구분 탭: 장비사진 / 개선사진 / 교육사진 / 집중진단
- 실(폴더)별 업로드: 방송실 · 강당/체육관 · 시청각실 · 특별실 · 다목적실 · 소강당 · 기타실
  - 각 [사진 찾기] + 선택 파일 수 + 업로드 상태
- 액션: 저장 / 완료 / 로그아웃
- ※ admin 공지: 사진 업로드 후 수정 불가

### 5.5 방송장비 컨설팅 보고서 (`/docs/consulting` → `/pms/broadcast-consulting/new`)
- 진입 화면: "새로작성 → PMS 템플릿 화면 이동". 부제 "작성은 `C:\broadcast_pms_offline` 템플릿 사용"
- **PMS 작성 템플릿** (핵심, 방대):
  - 헤더: 작성회차(1차/2차), 만족도 조사 QR(`http://ksurv.kr/...`), 버전 배지(RESTORE / CHECKLIST GUARD), 테마/중복OFF 토글
  - 시설 체크박스: 방송실 / 시청각실 / 강당·체육관 (해제 시 저장·출력에서 제외)
  - 학교 기본 정보: 기존보고서 불러오기(학교명→최신 보고서 자동채움), 교육지원청, 학교명, 소재지, 컨설팅 방문일, 유지관리 현황(매월/분기별/비정기/없음), 수능시험장 여부(예/아니오)
  - 컨설팅 사항(행추가): 시설별 점검항목 테이블 [점검항목 · 장비 · 장애 · 동작상태 · 조치내용 · 조치 · 분야 · +]
    - 각 항목: 점검내용/기준 설명 + 시급성(상/중/하)
  - 방송실 점검항목 예: 전원 공급 상태 / 오디오 장비 구성 / 음향 입·출력 신호 / 교내 비상·일반 방송 출력 / 영상장비 구성 / 콘솔·랙 케이블 정리 / 개선·조치 사항
  - 시청각실·강당체육관 섹션 반복

## 6. 코드북(마스터 데이터) — 컨설팅 템플릿 내장

선택 시 설명 자동 표시. 클론 시 별도 마스터 테이블로 관리 필요.

- **장비 코드(장비 유형)**:
  - `PA-001~042` 방송장비(PA: MAIN CONTROLER, EMERGENCY PANEL, ... 하이임피던스 스피커 등)
  - `AU-001~025` 음향장비(AUDIO MIXER, GRAPHIC EQUALIZER, WIRELESS MIC 등)
  - `VI-001~039` 영상장비(A/V SWITCHER, HDMI MATRIX, LED TV, 전자칠판, 빔프로젝터 등)
  - `ETC-001~013` 기타(UPS, 순차전원, 무대조명, 전자교탁 등)
- **장애(Fault) 코드**: `F-AUD`(음향 30종), `F-CTR`(제어), `F-ENV`(환경), `F-SLT`(조명/모터), `F-NET`(네트워크), `F-PWR`(전원), `F-SAF`(안전), `F-VID`(영상) 계열
- **조치(Action) 코드**: `A-AUD`, `A-CAB`(케이블), `A-MNT`(유지보수), `A-NET`, `A-SLT`, `A-PWR`, `A-SET`, `A-VID` 계열
- **분야**: 음향 / 영상 / 조명 / 기타

## 8. 문서함

### 8.1 저장(DRAFT) 문서함 (`/docs/saved`)
- 5종 유형별 카드(건수 + 최근시각), 열기 → 목록(선택삭제/열기)
- 예시 건수: 컨설팅 5 / 장비목록 1 / 스피커선로 2 / 개선 3 / 방송사진 1

### 8.2 완료(DONE) 문서함 (`/docs/completed`)
- 5종 유형별 카드(건수 + 최근시각), 열기 → 목록(선택삭제/PDF 출력)
- 예시 건수: 컨설팅 109 / 장비목록 108 / 스피커선로 0 / 개선 47 / 방송사진 108
- 컨설팅 원본/요약 PDF 출력 지원(1차/2차/기존 데이터 포함)

## 9. 상태 모델(추정)

- 문서 상태: **DRAFT(저장)** → **DONE(완료)**
- 컨설팅 보고서: 1차 / 2차 회차 구분
- 완료 후 수정 불가(정책) — 통계 수치 확정
- 문서 유형 5종: consulting / equipment / speakerline / improvement / equipment_photos

## 10. 클론을 위해 확보해야 할 데이터/리소스

1. **학교 마스터** (`schools.json`, 1414교): 학교명, 교육지원청(11개), 소재지/주소, 학교급(초/중/고/기타), 수능시험장 여부 등
2. **장비 코드북**: PA/AU/VI/ETC 전체 항목 (본 문서 6장에 일부 캡처, 전체 필요)
3. **장애 코드북**: F-* 전체
4. **조치 코드북**: A-* 전체
5. **점검항목 정의**: 시설(방송실/시청각실/강당체육관)별 점검항목 + 점검내용/기준 문구
6. **개선내용/설치위치 옵션 목록**
7. (선택) 실제 reports 데이터는 클론 시 불필요 — 스키마만 있으면 됨
